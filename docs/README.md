## Adding tasks to do within a period

Use `within` to record a task that may be completed anytime between two inclusive dates.
Enter both dates in `yyyy-MM-dd` format.

Example:

```text
within collect certificate /from 2026-09-15 /to 2026-09-25
```

Trackie responds with:

```text
Got it. I've added this task:
  [W][ ] collect certificate (from: Sep 15 2026 to: Sep 25 2026)
Now you have 1 task in the list.
```
